# Support

Need help with an ElianCodes project? Here's where to look. 👇

## 📚 Documentation

Start with the project's `README.md` and any `docs/` folder in the repository. Most common
questions are answered there.

## 💬 Questions & discussion

- **GitHub Discussions** — for questions, ideas, and general conversation:
  [github.com/orgs/eliancodes-com/discussions](https://github.com/orgs/eliancodes-com/discussions)
- Search existing issues and discussions first — your question may already be answered.

## 🐛 Bugs & feature requests

- Found a bug? [Open an issue](https://github.com/eliancodes-com) using the **Bug report** template.
- Have an idea? Use the **Feature request** template.

Please **don't** use issues for general support questions — use Discussions for those.

## 🔒 Security issues

Do **not** open a public issue for security vulnerabilities. Follow our
[Security Policy](./SECURITY.md) instead.

## 📬 Business & project inquiries

Looking to hire us or discuss a project? Reach out directly:

- **Email:** [hello@elian.codes](mailto:hello@elian.codes)
- **Web:** [elian.codes](https://elian.codes)

We'll get back to you as soon as we can.
