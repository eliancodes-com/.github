# `.github`

This is the **organization-wide `.github` repository** for [ElianCodes](https://github.com/eliancodes-com).

GitHub uses it as a fallback for community health files and org-level defaults: any repository
in the `eliancodes-com` organization that doesn't define its own version of these files will
inherit the ones here. It also hosts the public **organization profile**.

## What's in here

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](./profile/README.md) | The public profile shown on the [organization page](https://github.com/eliancodes-com). |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | How we expect everyone to behave in our spaces. |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Default guide for contributing to our repositories. |
| [`SECURITY.md`](./SECURITY.md) | How to responsibly report a security vulnerability. |
| [`SUPPORT.md`](./SUPPORT.md) | Where to get help. |
| [`.github/FUNDING.yml`](./.github/FUNDING.yml) | Sponsorship / funding links. |
| [`.github/CODEOWNERS`](./.github/CODEOWNERS) | Default code ownership. |
| [`.github/PULL_REQUEST_TEMPLATE.md`](./.github/PULL_REQUEST_TEMPLATE.md) | Default PR template. |
| [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE) | Default issue templates (bug report, feature request). |

## How overrides work

These files are **defaults**. A repository can override any of them by committing its own
version at the standard location (repo root or its own `.github/` folder). When present, the
repo's local file always wins.

## Maintaining this repo

Keep changes small and reviewed — every repo in the org feels them. Open a PR rather than
pushing to `main` directly.
